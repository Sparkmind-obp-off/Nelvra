# Nelvra — Brand Look Direction

## Status

**Draft visual direction pending final brand lock.**

The purpose of this document is to give designers and implementers a stable visual direction without pretending the identity is legally final.

## Core visual idea

**Quiet control.**

Nelvra should visually communicate that the operator is in control of:

**Stock → Outlet → Cash → Profit**

The identity should feel operational and premium because it is organized, not because it is luxurious.

## Wordmark

Primary treatment:

**NELVRA**

Recommended direction:

- uppercase wordmark
- geometric or neo-grotesk letterform
- medium/semi-bold weight
- moderate tracking
- strong horizontal rhythm
- no decorative ligatures

The wordmark should remain legible at small app sizes.

## Symbol direction

Build a simple abstract symbol from:

- movement
- transition
- convergence
- controlled flow

A possible construction is a pair of directional paths that converge into a stable form.

Do not use literal:

- truck
- warehouse
- barcode
- coin
- snack/package illustration
- map pin

The system should feel broader than logistics.

## Color direction

Use a restrained neutral-first interface.

### Foundation

- near-black / graphite text
- warm or soft off-white background
- muted secondary neutrals

### Accent

Choose one distinctive brand accent for:

- primary actions
- positive movement
- active navigation
- selected states

Avoid rainbow dashboards and excessive semantic colors.

Semantic colors should be used only when meaning requires them:

- success
- warning
- critical
- inactive

## Typography

Primary requirement:

**legibility of operational numbers.**

Typography should optimize:

- compact tables
- currency
- quantity
- timestamps
- status labels
- mobile scanning

Avoid overly geometric display fonts for data-heavy areas.

## UI shape language

- moderate corner radius
- compact cards
- clear borders/dividers
- dense but readable data hierarchy
- large numeric anchors
- restrained iconography
- obvious primary actions

## Core UI hierarchy

The interface should prioritize:

1. What needs attention now?
2. What money is due?
3. What stock needs movement?
4. Which outlet should be visited?
5. What should the operator do next?

## Brand voice

Use short, decisive language.

Prefer:

**COLLECT TODAY**

over:

**View collection opportunities**

Prefer:

**RESTOCK 3 OUTLETS**

over:

**Recommended inventory replenishment**

Prefer:

**STOP RESTOCK**

over:

**Low-performance replenishment recommendation**

## Prohibited brand behavior

Do not make the product look like:

- a generic AI dashboard
- a cryptocurrency/fintech product
- a luxury fashion brand
- a fleet tracking application
- a traditional accounting system

## Brand-look acceptance test

A finished identity should still look credible in:

- favicon
- mobile app icon
- field PWA
- desktop dashboard
- printed invoice/settlement document
- sales proposal
- pilot report

The brand must remain clear without relying on gradients, 3D effects, or oversized illustrations.
