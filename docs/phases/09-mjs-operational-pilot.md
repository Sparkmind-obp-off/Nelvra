# PHASE 9 — MJS OPERATIONAL PILOT

## Objective
Validate whether Nelvra creates measurable operational and economic improvement in actual MJS Snack operations.

## Pilot principle
MJS is a design partner and evidence source, not a reason to hardcode one customer's workflow into the product.

## Stage 1 — Baseline
Measure current operation before relying on Nelvra recommendations.

Capture:
- weekly/monthly sales proxy
- stock placed
- stock sold
- stock returned
- outstanding
- collection cycle
- route expenses
- visit time
- slow/dead stock
- stockouts.

## Stage 2 — Controlled use
Use Nelvra for actual:
- stock movement
- outlet visits
- restock
- returns
- collection
- route prioritization.

## Stage 3 — Compare
Compare baseline and pilot periods using consistent definitions.

## Stage 4 — Refine
Adjust:
- thresholds
- cadence
- action ranking
- UI friction
- calculation rules.

## Success metrics
- sell-through ↑
- stockout frequency ↓
- slow/dead stock value ↓
- collection cycle ↓
- route contribution ↑
- outlet contribution ↑
- inventory turnover ↑
- visit time ↓
- reconciliation error rate ↓.

These are target directions, not guaranteed outcomes.

## Pilot acceptance
- transaction accuracy is reliable
- field workflow is usable
- collection tracking is trusted
- recommendations are understandable
- measurable improvements appear in multiple leading indicators.

## Exit gate — PILOT VALIDATED
MJS has used the system in real operations and the evidence is sufficient to decide what should be retained, changed, or productized.
